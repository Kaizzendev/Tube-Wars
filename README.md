# 🎮 Tube wars — Rts protoype 
**Tube wars** is an *rts/ node conquer* protoype developed in **Unity (C#)** where you control a team with different sctructures and the goal is to conquer every team sctructure

This project is part of my **Game Developer portfolio**, demonstrating advanced gameplay systems and programming skills.

---
## 🔹 Overview
In *Tube wars*, the player can:
- 🤖 **Face enemies** with modular behavior using a **Utility System AI**.

- 🏫 **Conquer and upgrade** buildings.
---
## 🧠 Skills Demonstrated
 **Code Architecture & Patterns** -> OOP, Utility System AI, Object pooling , Event driven |

 **Unity Development** -> Player mechanics, AI behaviors, custom tool for level design |
